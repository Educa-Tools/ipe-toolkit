Sobre el proyecto

¿Qué es el IPE Toolkit?

El IPE Toolkit nació para digitalizar la creación empresarial en el aula de FP. Cada herramienta guía al alumno a través de un paso concreto del plan de empresa, generando un entregable técnico y visual que puede presentar directamente al profesor o incorporar a su dossier.

La metodología es activa y orientada a resultados: el alumno aprende haciendo, no memorizando. Las herramientas se pueden usar de forma secuencial para construir el plan de empresa completo, o de forma independiente para trabajar contenidos concretos de cada módulo.
